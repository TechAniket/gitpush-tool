FAQ

  

    

      

        GitHub password se push nahi ho raha?
        ▼
      

      
GitHub ne password auth band kar diya hai. Ab Personal Access Token use karo. GitHub → Settings → Developer settings → Personal access tokens → Generate new token → repo scope check karo. Woh token password ki jagah paste karo.

    

    

      

        Mac pe permission denied error?
        ▼
      

      
Run karo: chmod +x push.sh — phir ./push.sh chalao. Ya seedha bash push.sh bhi kaam karta hai.

    

    

      

        Script safe hai? Mera token store hota hai kya?
        ▼
      

      
Bilkul safe. Ye tool sirf browser mein kaam karta hai — koi data server pe nahi jata. Script mein koi token store nahi hota. GitHub ka credential helper OS-level pe store karta hai securely.

    

    

      

        Private repo ke liye kaam karega?
        ▼
      

      
Haan. Bas token mein repo scope hona chahiye (not just public_repo). Private repos ke liye full repo access zaroori hai.

    

    

      

        Ek se zyada repos ke liye alag alag script banana padega?
        ▼
      

      
Haan — har repo ke liye ek baar generate karo. Username + repo name change karo, download karo, us folder mein rakho. 10 seconds kaam hai.
